# Live Matches

A Stremio-protocol addon for Nuvio that serves **live sport channels** whose
streams sit on **unsigned CDN endpoints** — so playback keeps working even if
the source site disappears.

This is the whole design goal: **the site is a discovery source, not a
dependency.**

---

## How it survives the site going down

The player-facing URL the source site uses looks like this:

```
https://vix.cdnfan.site/tflix/secure/<64-hex-hash>/<expiry-timestamp>/NHL-1.m3u8
```

That carries a signature and an expiry, so it is useless to us — and it is
generated by an obfuscated script on the embed host.

But the **bare path serves the same playlist** with neither:

```
https://vix.cdnfan.site/tflix/NHL-1.m3u8     ← works, no signature, no expiry
```

Verified directly: strip the hash and timestamp and the endpoint still returns
a valid `#EXTM3U` playlist. So:

- **No signing step is needed** — we never have to reproduce their tokens
- **Nothing expires** — the URL stays valid
- **The source site is only used to discover which events exist**, and that
  happens on a schedule, not at request time
- If the site is down, the addon is **unaffected** — it serves the committed list

Segments ultimately come from TikTok's CDN (`p16-common-sign.tiktokcdn-us.com`);
they relay live streams.

## Layout

```
matches.js                 the static channel list  (generated — do not edit)
worker.js                  the addon
_worker.js                 Cloudflare Pages entry point
tools/refresh.js           discovers events + verifies each URL
.github/workflows/refresh.yml   runs the refresh every 30 minutes
wrangler.toml              for the Worker route, if you prefer it
```

---

## Deploy

Cloudflare Pages, same shape as the catalog addon:

1. **Workers & Pages → Create application → connect this repository**
2. **Build output directory:** the repository root (the default)
3. Deploy

Manifest URL:

```
https://<project>.pages.dev/manifest.json
```

⚠️ Use the bare production domain, not the per-commit `<hash>.` previews.

`_worker.js` must sit in the output directory — that is how Pages knows to run
code rather than serve the repository as static files.

### Or as a Worker

`wrangler.toml` is set up for it:

```bash
npx wrangler deploy
```

## Channels

The list is generated and grouped into three catalogs:

| Catalog | Contents |
|---|---|
| **Live Matches** | everything live |
| **Football** | La Liga, Arena Sport, Libertadores… |
| **Other Sport** | NHL, NFL, NBA, UFC, WWE… |

Each entry is verified at refresh time, so a channel only appears if its CDN
endpoint actually answered. Events that are not currently live are dropped
rather than listed as dead entries.

---

## Maintenance

**The list refreshes itself.** `.github/workflows/refresh.yml` runs every 30
minutes, rebuilds `matches.js`, and commits only if something changed.

**If channels stop appearing**, the CDN has moved. Update the `CDN` constant at
the top of `tools/refresh.js` — that is the single point of change — and re-run.

**If the source site changes**, update `SITE` and `EMBED_RE` in the same file.

**Adding another source** is a matter of writing another discovery function and
appending its verified results. The addon does not care where a channel came
from; it only needs `id`, `name`, `sport` and `url`.

## Local use

```bash
node tools/refresh.js          # rebuild matches.js
node --input-type=module -e '
  const m = await import("./_worker.mjs");
  const r = await m.default.fetch(new Request("https://x/manifest.json"), {});
  console.log(await r.text());
'
```
